# Parking System

A simple and beginner-friendly **Parking System built with React.js**. This project allows users to manage parked vehicles, calculate parking earnings, search for registration numbers, and remove vehicles when they leave.

## Features

- **Park In:** Register a car or bike using its registration number.
- **Vehicle Selection:** Select a car or bike using radio buttons.
- **Total Earnings:** Calculate parking fees automatically.
- **Search Vehicles:** Search for a vehicle by registration number.
- **Park Out:** Remove a vehicle from the parked vehicles list.
- **React State Management:** Use React's `useState` hook to manage application data.
- **Simple User Interface:** Easy-to-use interface with green and yellow styling.
